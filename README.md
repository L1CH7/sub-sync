# SubSync (Local Subscription & Header Relay)

Легковесный локальный ретранслятор профилей конфигурации для десктопных сетевых клиентов (Clash, sing-box, v2rayN).

Позволяет централизованно обновлять подписку и передавать необходимые клиентские заголовки без повторной ручной настройки на каждом рабочем месте. Поддерживает Linux и Windows.

---

## Возможности

- **Полная автономность**: работает исключительно локально на вашем ПК, не использует сторонние облачные сервисы.
- **Изоляция данных**: конфигурация и сертификаты хранятся локально в `data/` и исключены из системы контроля версий.
- **Работа без root/admin**: автозапуск настраивается в пользовательском пространстве (`systemd --user` / папка автозагрузки Windows).
- **Интерактивный TUI**: быстрое управление через терминальный интерфейс с поддержкой одиночных нажатий клавиш.

---

## Быстрый запуск

### Windows
Запустите `setup.cmd` двойным кликом в Проводнике или выполните в PowerShell:
```powershell
.\setup.ps1
```

### Linux
```bash
./setup.sh
```

Менеджер окружения `uv` проверяется и устанавливается автоматически при первом запуске.

## Интерфейс управления

После запуска отображается текущее состояние конфигурации и параметров подключения:

```text
+---------------------- SUBSYNC CONFIGURATION MANAGER -----------------------+
|  Служба автозапуска      [OK]      Установлена (запуск при старте ПК)        |
|  Локальный адрес         [IP]      192.168.1.50                              |
|  Адрес прокси на ПК      [URL]     http://127.0.0.1:54321/sub                |
|                                                                              |
| Конфигурация прокси (JSON-дерево)                                            |
| ├── Ссылка подписки (target_url)                                             |
| │   └── https://provider.example.com/sublink/xxx...                          |
| └── Заголовки клиента (VLESS / ядра) (9 параметров)                          |
|     ├── User-Agent: Mozilla/5.0 ...                                          |
|     ├── X-HWID: a1b2c3d4e5f6...                                              |
|     └── ...                                                                  |
+------------------------------------------------------------------------------+

 [1] Настройка с телефона (единый QR-код: ссылка + сертификат + клиент)
 [2] Управление службой автозапуска (установка, статус, удаление)
 [3] Проверить работу прокси в консоли
 [4] Перенос конфигурации (экспорт / импорт / файл config.json)
 [r] Сбросить настройки
 [q] Выход
```

---

## Перенос на другой компьютер

Для переноса настроек на новый ПК достаточно скопировать файл:
```text
data/config.json
```
в аналогичную директорию на целевой машине. Также доступен перенос через строку бандла в меню `[4]`.
